# 探索方向与实验记录

本文件用于跟踪 AI × Godot 各个方向的调研进度与结论。新增方向请复制下面的模板。

## 方向模板

```
### [方向名称]
- 状态: 调研中 / 实验中 / 已跑通 / 搁置
- 目标: 一句话描述要验证什么
- 关键问题: 需要搞清楚的技术点
- 参考: 链接 / 文档
- 结论: 跑通后的总结（或踩坑记录）
```
